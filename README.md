# Lyntin

Lyntin is a MUD client written entirely in Python, created by **Lyn Headley**.
It exposes the Python interpreter to the user, so aliases, triggers, and bots
can be full Python programs that interface with the client's own code.
Lyntin was later maintained by Will Guaraldi and contributors on SourceForge.

This repository is a conversion of the original SourceForge CVS repository,
preserving the full commit history (2000-2007). It contains three trees:

- `lyntin/` - the original Lyntin (1.x-3.x series)
- `lyntin40/` - the 4.x series, the last released line
- `lyntinng/` - the experimental "next generation" rewrite

Historical releases are preserved as tags (`R_2_0_2` through `rel-4-1-1`) and
the original CVS branches are kept as git branches.
